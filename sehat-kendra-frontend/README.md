# Caresse × SEHAT KENDRA update

This build keeps the existing SEHAT KENDRA UI pattern and adds the Caresse ADHD/Dyslexia flow described in the supplied PDF.

## Main changes
- Replaced **Continue as Guest** with **ADHD & Dyslexic People Registration**.
- Added a simple 3-step, readability-first registration flow.
- Saves the Caresse profile in browser `localStorage`.
- After registration: **Continue to Dashboard** or **Continue to Caresse App**.
- Added the Caresse bottom navigation: Learn / Dashboard / Accessibility.
- Added requested Accessibility, Learn, and Dashboard feature screens as interactive frontend prototypes.
- Feature assets/code are organized under:
  - `Accessibility/`
  - `Learn/`
  - `Dashboard/`

## Run
Open `index.html` in a browser, or serve the folder with a local static server.
